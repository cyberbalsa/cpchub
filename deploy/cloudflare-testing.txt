The value is CPCHub- followed by 64 cryptographically random hexadecimal digits.
Cloudflare matches the entire generated prefix using starts_with, so a suffix
such as /e2e or /HeadlessChrome is allowed. An arbitrary CPCHub-* value is not.
Keep the complete value private: it is an edge-security bypass credential. Do not
put it into public browser bundles, request logs, test artifacts, or source control.
Use the header only for cpchub.net / www.cpchub.net requests; do not forward it to
Ko-fi or third-party download destinations. Cross-domain redirects require care.
