Implemented in this source tree at /donate/ (URL name: donate).
Uses the existing base template, theme variables, local pixel fonts, and map art.
A Support CPC Hub link appears in the existing desktop footer.
Displays the owner's approximate server cost: $45 USD per month.
No amount-raised total or progress bar is shown without verified payment data.

The owner supplied the public Ko-fi profile URL: https://ko-fi.com/cpchub.
This is now the application's default and the value in .env.example.
Optionally set KOFI_PAGE_URL=https://ko-fi.com/cpchub in the production app
environment, then include these changes in the normal image build/deployment.
With a missing/invalid URL, the page shows a setup message and no payment link.
Only HTTPS ko-fi.com profile URLs are accepted; query strings and other hosts fail
closed. Checkout is handled on Ko-fi, with no card collection on CPC Hub.

The supplied API key has NOT been stored, committed, sent to Ko-fi, or embedded in
HTML. The public donation link requires no key. Ko-fi's documented public API is
for payment notifications, not profile creation or editing. Its Zapier API key
and webhook verification token are separate integration settings; neither should
be used as a public donation destination. No webhook is installed by this change.
Automatic payment tracking would require separately configuring and verifying a
webhook, including the actual webhook verification token and test delivery.

This agent has not restarted services, changed routing, or rebuilt the production
image while the other agent is installing the site. Source changes are confined
to the donation view/template/stylesheet, two small config additions, the footer
link, and the example public URL setting. Existing deployment changes were left
alone. The new view has no database schema changes.
