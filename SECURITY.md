# Reporting a problem

Report security vulnerabilities through [GitHub's private reporting form](https://github.com/cyberbalsa/cpchub/security/advisories/new).

For critical issues, message **Balsa.38** on Signal. Start a new message and enter the full username.

Include the affected page or version, steps to reproduce the issue, and its impact.

For other bugs and feature requests, [open a GitHub issue](https://github.com/cyberbalsa/cpchub/issues).
