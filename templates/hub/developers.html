Connect through the browser

  1. Register your manager.

    The site operator registers a public OAuth client and its HTTPS or loopback callback. No embedded client secret is needed.

  2. Open the system browser.

    Send the user to /o/authorize/ with a random state and an S256 PKCE challenge. The user signs in with a CPC Hub account, or Steam or Discord when enabled, then approves the requested permissions.

  3. Exchange the code.

    Verify state, then POST the authorization code and original verifier to /o/token/. Access tokens last 15 minutes; refresh tokens rotate.

  4. Use the API or create a key.

    Use Authorization: Bearer <token>. If the user approved keys:write, POST to /api/v1/keys/ for a separate key with equal or narrower read/write permissions.

Store credentials in the operating system credential store. Users can revoke the manager and all its keys from their control panel.

Files & versioning

Discover categories and accepted extensions at /api/v1/types/. ZIPs can contain packs or multiple mod files. Native game formats are stored without modification.

Create metadata, upload an immutable release, add screenshots, then publish. Each release returns a stable ID, version, original filename, size and SHA-256. Download by release ID and verify the checksum before installation.

Download and screenshot URLs redirect to signed storage URLs that expire after five minutes by default. Follow the redirect without forwarding your CPC Hub Authorization header. Keep the application URL and request it again when the signed link expires.

Installation paths and game-format validation are the manager’s responsibility. Archives are never extracted by this server.

quickstart.txt

Browse public creations

curl '{{ public_url }}/api/v1/items/?type=blueprints'

Read your profile

curl '{{ public_url }}/api/v1/me/' \
  -H 'Authorization: ApiKey YOUR_KEY'

Create a key for your manager

POST /api/v1/keys/
Authorization: Bearer ACCESS_TOKEN
Content-Type: application/json

{
  "name": "My mod manager",
  "scopes": ["read"],
  "days": 90
}

Choose your permissions

read
Read the catalog, your drafts and profile.
write
Create and edit your items, releases and screenshots.
keys:write
Let a manager create and revoke its own scoped keys.
