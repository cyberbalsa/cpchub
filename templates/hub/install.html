Install blueprints & scenarios

  1. Download a blueprint (.cpbp) or scenario (.cpcs) from CPC Hub.
  2. In your Steam library, right-click Car Park Capital and choose Manage → Browse local files.
  3. To use a blueprint in a normal game, copy its .cpbp file into one of the parking garage folders under assets/blueprints.
  4. For scenarios, copy the .cpcs file into saves/scenarios.
  5. Restart the game to load the new files.

Folder locations

Find the blueprint folders under Car Park Capital/assets/blueprints/.

On Windows, the scenario folder is usually:

C:\Program Files (x86)\Steam\steamapps\common\Car Park Capital\saves\scenarios

On Linux:

~/.local/share/Steam/steamapps/common/Car Park Capital/saves/scenarios

If Steam uses another library or you installed it through Flatpak, use Browse local files to find the right folder.
